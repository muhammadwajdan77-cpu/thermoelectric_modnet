WHAT IS l-MM DESCRIPTOR?
================================================================================

l-MM Features (Liquid-Metals Material Model):
  • Dimension: 758 numerical features per structure
  • Type: Learned from MEGNet pre-trained model
  • Captures: Electronic structure, chemical properties, structural information
  • Application: Machine learning predictions of material properties
  • Coverage: Works for any crystal structure

Feature Categories (758 total):
  • Atomic properties: ~100 features per element type
  • Structural descriptors: ~200 features
  • Symmetry operations: ~100 features
  • Graph-based features: ~200 features
  • Other derived features: ~58 features

Why 758 Features?
  • Comprehensive representation of crystal structure
  • Pre-trained by MEGNet on millions of structures
  • Suitable for thermoelectric property prediction
  • Transferable across different material systems

  • These are skipped automatically
  • Logged as warnings
  • Impact: ~10-20 files out of 5,708 (~0.2%)

Issue 2: Slow Feature Extraction
  • MatterVial may take 1-3 seconds per structure
  • Total time: 2-4 hours for all 5,708 structures
  • This is normal - MEGNet is computationally intensive
  • Cannot be easily parallelized due to GPU memory constraints

Issue 3: Missing zT Values
  • Only compositions in SysTEm dataset will have zT values
  • Expected: 30-50% of structures will have zT
  • Others will have NaN in zT column
  • Can still be used for unsupervised learning or transfer learning

Workaround for Slow Processing:

  • Or: Run multiple instances on different composition ranges
  • Script supports manual start/stop at specific indices
